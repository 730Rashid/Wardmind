{# The go-live status as a tag. The icon and the word carry the state; the colour only repeats it: on track is the healthy green, late is the at-risk red, and the two states with no forecast yet are neutral slate. With short=True (the picker's column) the tag is followed by how the pace puts the finish against the window: "5 days late", "3 days to spare" or "On time". #} {% macro golive_tag(forecast, short=True) -%} {%- set state = forecast.status.value -%} {%- if state == "on_track" -%} {{ forecast.status.label }} {%- elif state == "late" -%} {{ forecast.status.label }} {%- else -%} {{ forecast.status.label }} {%- endif -%} {%- if short and state == "late" %} {{ forecast.overrun_days }} {{ 'day' if forecast.overrun_days == 1 else 'days' }} late {%- elif short and state == "on_track" and forecast.overrun_days == 0 %} On time {%- elif short and state == "on_track" %} {{ -forecast.overrun_days }} {{ 'day' if forecast.overrun_days == -1 else 'days' }} to spare {%- endif -%} {%- endmacro %}
